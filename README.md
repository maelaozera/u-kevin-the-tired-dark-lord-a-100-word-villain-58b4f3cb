## The entry

A monologue of exactly 100 words, spoken by a fantasy villain who is
secretly just very tired. The tiredness is never announced — it lives in
the rhythm: short sentences, pauses, small deflections. He has waited six
hundred years for the chosen one, heard four heroes out (one wept, one
brought a lute, this one brought a packed lunch), lost his dragon to a
long commute, and let his curse expire unnoticed. He is still a villain —
he offers the hero the throne, on one condition: the kettle stays. It is
the only thing here that still loves him.

## How to run

Requires Node 22 or later, no dependencies:

```sh
node main.ts
```

It writes the monologue to `/output/entry.txt` and self-checks before
writing: exactly 100 words, 1–600 characters, non-blank. It exits with an
error if any check fails.
